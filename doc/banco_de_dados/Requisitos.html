Documentação do Sistema de Banco de Dados

Requisitos do Sistema

  • Sistema para armazenar vários tipos de estoques, por exemplo, ferramentas e consumíveis.
  • Armazenamento das movimentações em um log que pode ser consultado posteriormente.

Detalhamento dos Requisitos das Tabelas:

  • Tabela Produtos: Armazenar informações sobre os produtos, como nome e valor.
  • Tabela Estoques: Registrar estoques disponíveis ao negócio, como nome e descrição.
  • Tabela Produto_Estoque: Tabela de relacionamento entre Produtos e Estoques para registrar a quantidade de cada produto em cada estoque.
  • Tabela Funcionários: Manter informações sobre os funcionários envolvidos nas movimentações de estoque.
  • Tabela Movimentações: Registrar cada movimentação de estoque, incluindo data, tipo (entrada/saída), produto, quantidade e funcionário responsável.

Script de Criação do Banco de Dados:


-- Script para criação do banco de dados e tabelas

-- Criar o banco de dados (se ainda não existir)
CREATE DATABASE IF NOT EXISTS estoque_db;
USE estoque_db;

-- Tabela Produtos: Armazenar informações sobre os produtos, como nome e valor.
CREATE TABLE IF NOT EXISTS Produtos (
    ProdutoID INT AUTO_INCREMENT PRIMARY KEY,
    Nome VARCHAR(100) NOT NULL,
    Valor DECIMAL NOT NULL
);

-- Tabela Estoques: Registrar estoques disponiveis ao negocio, como nome e descricao
CREATE TABLE IF NOT EXISTS Estoques (
    EstoqueID INT AUTO_INCREMENT PRIMARY KEY,
    Nome VARCHAR(100) NOT NULL,
    Descricao TEXT
);

-- Tabela Produto_Estoque: Tabela de relacionamento entre Produtos e Estoques para registrar a quantidade de cada produto em cada estoque.
CREATE TABLE IF NOT EXISTS Produto_Estoque (
    ProdutoEstoqueID INT AUTO_INCREMENT PRIMARY KEY,
    ProdutoID INT,
    EstoqueID INT,
    Quantidade INT,
    FOREIGN KEY (ProdutoID) REFERENCES Produtos(ProdutoID),
    FOREIGN KEY (EstoqueID) REFERENCES Estoques(EstoqueID)
);

-- Tabela Funcionários: Manter informações sobre os funcionários envolvidos nas movimentações de estoque.
CREATE TABLE IF NOT EXISTS Funcionarios (
    FuncionarioID INT AUTO_INCREMENT PRIMARY KEY,
    Nome VARCHAR(100) NOT NULL
);

-- Tabela Movimentações: Registrar cada movimentação de estoque, incluindo data, tipo (entrada/saída), produto, quantidade e funcionário responsável.
CREATE TABLE IF NOT EXISTS Movimentacoes (
    MovimentacaoID INT AUTO_INCREMENT PRIMARY KEY,
    Data DATE,
    Tipo ENUM('ENTRADA', 'SAIDA'),
    ProdutoID INT,
    Quantidade INT,
    FuncionarioID INT,
    FOREIGN KEY (ProdutoID) REFERENCES Produtos(ProdutoID),
    FOREIGN KEY (FuncionarioID) REFERENCES Funcionarios(FuncionarioID)
);
